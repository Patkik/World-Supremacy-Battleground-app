# Project skill library

Read the matching SKILL.md before applying a workflow.

## Domain & engineering workflows

- [wsb-analyze](../.agents/skills/wsb-analyze/SKILL.md): Analyze WSB requirements, rule provenance, scope and acceptance criteria.
- [wsb-architect](../.agents/skills/wsb-architect/SKILL.md): Design WSB tenant boundaries, Firebase data contracts and offline protocols.
- [wsb-implement](../.agents/skills/wsb-implement/SKILL.md): Implement a bounded WSB feature from acceptance criteria through verification.
- [wsb-design](../.agents/skills/wsb-design/SKILL.md): Design WSB registration, judging and event-day user experiences.
- [wsb-verify](../.agents/skills/wsb-verify/SKILL.md): Review WSB authorization, scoring, payments and offline recovery behavior.
- [wsb-memory](../.agents/skills/wsb-memory/SKILL.md): Maintain WSB durable memory, cited retrieval and the task dependency DAG.

## Route-scoped UI/UX skill stack (`apps/web`)

Frontend directory rules live in [apps/web/AGENTS.md](../apps/web/AGENTS.md). Always load `wsb-ui-ux-architect` first on UI work, then pair with the surface-appropriate skills below:

- [wsb-ui-ux-architect](../.agents/skills/wsb-ui-ux-architect/SKILL.md): Master WSB Three-Surface design system (`Spectacle`, `Tactical Auditorium`, `Broadcast Arena HUD`), semantic CSS tokens, typography, motion choreography, and judging ergonomics.
- [ui-ux-pro-max](../.agents/skills/ui-ux-pro-max/SKILL.md): Searchable UI/UX intelligence library (styles, palettes, font pairings, UX guidelines, contrast/reflow checks) across all surfaces.
- [frontend-design](../.agents/skills/frontend-design/SKILL.md): Creative direction and anti-slop guardrails for street-dance championship identity (`(marketing)` and `(arena-live)`).
- [build-awwwards-quality-sites](../.agents/skills/build-awwwards-quality-sites/SKILL.md): Hero intro timelines, single-engine Lenis + ScrollTrigger choreography, kinetic reveals, and optional shaders (`(marketing)` only — forbidden in `(console)` and `(portal)`).
- [gsap](../.agents/skills/gsap/SKILL.md): Production React 19 `useGSAP()` scoping, `contextSafe` handlers, compositor-only transforms, and `gsap.matchMedia()` reduced-motion cleanup.
- [ui-craft](../.agents/skills/ui-craft/SKILL.md): High-density tactical ergonomics, forms, token hygiene, non-happy-path state coverage, and dark-venue contrast (`(portal)` and `(console)`).
