# Reference: feature coverage

This inventory maps introduced capabilities to the original paperwork problem and identifies the remaining scope. **Connected local** means an authoritative local path exists with recorded checks; it does not mean production-ready or that every proposed feature in that domain is complete.

## Work required to meet the complete original goal

Finish production identity/membership and remaining durable migrations; approve event rules and sensitive-data policies; complete guardian/consent and actual music processing. Validate PayMongo with controlled provider testing, including retries, cancellation and refund failure reconciliation. Complete signed passes/offline arrival, battle progression, advancement and global HQ decisions, then run an end-to-end organizer pilot with authorization, recovery and capacity evidence.

The [task DAG](../../workflows/tasks.json) tracks domain work in progress. This inventory does not change those implementation statuses or treat a documentation deliverable as completion of the system.
