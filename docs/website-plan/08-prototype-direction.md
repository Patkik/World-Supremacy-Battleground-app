# Representative visual prototype

Scope: home, event detail, event discovery, crew dashboard, a four-step sample
registration, judge desk and arena display. Supporting chapter/help/result routes
make navigation usable. This is a browser-local prototype with synthetic fixtures;
no production authentication, registration, upload, payment or score receipt.

Visual thesis: a dance championship campaign framed like a stage poster. A very
large Archivo Black title sits beside original dark, warm-lit dance concept art.
The original WSB logo appears intact. Charcoal/chrome/volt semantic tokens connect
the public experience, calm portal shell and high-contrast competition displays.

Home sequence: restrained top notice, identity/navigation, asymmetric hero,
event strip, editorial event rows, chapter discovery, participant journey, final
CTA and full footer. Readable server-rendered first frame; scoped GSAP enhancement.
Lenis is the only optional smooth-scroll engine, public routes only; reduced motion
uses native scrolling. No Three.js: a raster stage image provides sufficient depth
with lower load and rendering cost.

Portal sequence: event context, title and one primary action, readiness overview,
roster and event actions. Judge desk: event/current crew, large criterion controls,
numeric alternatives, draft state, optional notes and local preview save. Arena:
calibrated stage composition plus explicit sample-data indication.

All operational actions label browser-local persistence honestly. Synthetic score
criteria and event values demonstrate layout only and are not official rules.
Every design preserves phone portrait/landscape and tablet reflow; no fixed-height
rule can clip essential controls. Fonts are bundled locally. Solar icons come
from Iconify's package data; assets and concept-image provenance are recorded.
